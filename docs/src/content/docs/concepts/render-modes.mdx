---
title: Render input
description: Every render names a published project and template by slug, plus the data that fills the template.
---

Every render method (`Render.PdfAsync`, `Render.PdfStreamAsync`, `Render.DocumentAsync`, and the `RenderToFileAsync` helper) takes the same input, the sealed `RenderInput` record (see the [types reference](../../reference/types/)): a `Project` slug, a `Template` slug inside it, and a `Data` payload that fills the template's placeholders.

## Required fields

```csharp
byte[] pdf = await client.Render.PdfAsync(new RenderInput
{
    Project  = "billing",
    Template = "invoice",
    Data     = new Dictionary<string, object>
    {
        { "invoiceNumber", "INV-001" },
        { "total", 1280 },
    },
});
```

`Project`, `Template` and `Data` are `required` members, so leaving one out is a compile-time error. There is no version to pick: the API renders the project's copy published in the API key's environment (see [Authentication](../authentication/)). To render your own templates, publish the project to that environment first.

## Optional fields

- `Format` — a `PageFormat` (e.g. `PageFormat.A4`, `PageFormat.Letter`).
- `Orientation` — `Orientation.Portrait` or `Orientation.Landscape`.
- `Locale` — a BCP 47 tag (e.g. `"en-US"`).
- `Metadata` — your own primitive-valued audit data, echoed on the `DocumentDescriptor`.
- `IdempotencyKey` — overrides the auto-generated `Idempotency-Key` header; it is never sent in the body.

Unset optional fields are left out of the request body, so the API's defaults apply.

## Previews and inline HTML

The API renders published templates only. To preview a template or render inline HTML while you design it, use the playground at [play.poli.page](https://play.poli.page). `client.Documents.PreviewAsync(id)` returns the stored HTML of a document you already rendered.

## Example

```csharp
using PoliPage;

var client = new PoliPageClient(new PoliPageClientOptions
{
    ApiKey = Environment.GetEnvironmentVariable("POLI_PAGE_API_KEY")!,
});

byte[] invoicePdf = await client.Render.PdfAsync(new RenderInput
{
    Project     = "billing",
    Template    = "invoice",
    Data        = new Dictionary<string, object>
    {
        { "invoiceNumber", "INV-001" },
        { "total", 1280 },
    },
    Format      = PageFormat.A4,
    Orientation = Orientation.Portrait,
    Metadata    = new RenderMetadata { ["customerId"] = "cust_123" },
});
```
