Every failure thrown by the SDK is a `PoliPageException` or a subclass: API errors, network failures, timeouts, a cancellation (`aborted`), download failures and constructor validation. Catch the subclass for targeted handling; catch the base type to handle every SDK error in one place.

## The exception hierarchy

`PoliPageException` exposes four public properties: `Code` (a `PoliPageErrorCode` constant), `StatusCode` (HTTP status, `0` for network failures), `Message`, and `RequestId` (the `X-Request-Id` of the API's answer, `null` when no response was received). The underlying exception, when there is one (the `HttpRequestException` of a network failure, the `OperationCanceledException` of a cancellation), is the `InnerException`.

```csharp
using PoliPage;

try
{
    byte[] pdf = await client.Render.PdfAsync(input);
}
catch (PoliPageAuthException)          { await RefreshCredentialsAsync(); }
catch (PoliPageRateLimitException ex)  { await QueueForLaterAsync(ex.RetryAfter); }
catch (PoliPageNotFoundException)      { /* project / template / document missing */ }
catch (PoliPageValidationException ex) { /* malformed input — bad data */ }
catch (PoliPageException ex)
{
    Console.Error.WriteLine($"code={ex.Code} status={ex.StatusCode} requestId={ex.RequestId}");
    throw;
}
```

The wire-level error code is also surfaced verbatim through `PoliPageException.Code`. Compare against the `PoliPageErrorCode` constants instead of raw strings:

```csharp
catch (PoliPageException ex) when (ex.Code == PoliPageErrorCode.QuotaExceeded)
{
    // Not retried by the SDK: the quota lasts until the monthly reset.
}
```

The full code list lives in [the reference](../../reference/errors/).

## Example

```csharp
using PoliPage;

var client = new PoliPageClient(new PoliPageClientOptions
{
    ApiKey = Environment.GetEnvironmentVariable("POLI_PAGE_API_KEY")!,
});

try
{
    byte[] pdf = await client.Render.PdfAsync(new RenderInput
    {
        Project  = "billing",
        Template = "invoice",
        Data     = new Dictionary<string, object>
        {
            { "invoiceNumber", "INV-001" },
            { "total", 1280 },
        },
    });
}
catch (PoliPageException ex)
{
    Console.Error.WriteLine($"render failed: code={ex.Code} requestId={ex.RequestId}");
    throw;
}
```
